# finstat-bot - финансовый трекер

Асинхронный Telegram-бот для быстрого и удобного учета личных финансов.

## Функционал

* **Мгновенное добавление трат:** Пользователю достаточно отправить сумму расхода числом, после чего бот предложит выбрать нужную категорию с помощью кнопок.
* **машина состояний:** Реализован пошаговый ввод данных.
* **Валидация данных:** Встроенный механизм на базе регулярных выражений пропускает только числовые значения, защищая бота от падений при некорректном вводе.
* **Персональная статистика:** По команде `/stats` бот рассчитывает общую сумму расходов и выводит список трат за выбранный месяц, сгруппированный по категориям. Реализована навигация по месяцам с помощью инлайн-кнопок.
* **Чистка базы данных:** По команде `/clear` бот удаляет данные о тратах пользователя по его Telegram ID.
* **Справка по работе бота:** По команде `/help` можно получить основную информацию о функционале бота.
* **Изолированное хранение:** Данные разных пользователей хранятся раздельно благодаря привязке к Telegram ID.

## Архитектура проекта

Код разделен на модули для удобства поддержки:
* `main.py` - точка входа, инициализация и запуск бота.
* `handlers.py` - логика обработки команд, сообщений и нажатий на кнопки.
* `database.py` - логика работы с хранилищем данных.

## Стек технологий

* **Язык:** Python 3
* **Фреймворк:** `aiogram 3.x`
* **База данных:** локальное хранилище, чтение/запись через встроенный модуль `json`
* **Хранение токена:** `python-dotenv`

## Установка и запуск локально

1. **Клонируйте репозиторий:**
   ```bash
   git clone ...
   cd ВАШ_РЕПОЗИТОРИЙ
   ```
2. **Установите библиотеки:**
   ```bash
   pip install aiogram python-dotenv
   ```
3. **Настройте окружение:**
   * Создайте файл .env в корневой папке проекта.
   * Добавьте в него токен вашего бота, полученный у @BotFather:
     ```bash
     BOT_TOKEN=ваш_токен_бота_здесь
     ```
4. **Запустите бота:**
   ```bash
   python bot.py
   ```
